# UI languages (Russian / English)

EDHUD UI strings live in `edhud/i18n.py` under `_STRINGS["ru"]` and `_STRINGS["en"]`.

## Rules for new UI text

1. **Never** hardcode user-visible Russian or English in widgets, tooltips, menus, status lines or HUD builders.
2. Add a key to **both** `ru` and `en` in the same change.
3. Read the string with `t("key", …)` (or `jumps_word` for jump plurals).
4. If a label/button/heading is created once at startup, refresh it when language changes (`apply_look` / `refresh_i18n`).
5. Keep catalogs in sync: `tests/test_i18n.py` checks that both languages have the same keys.

## Where language is applied

- Settings → **Appearance and localization** → Interface language
- Saved as `language` in `config.json` (`ru` / `en`; empty = follow Windows)
- Applied at startup (`apply_config_language`) and again when settings are saved
